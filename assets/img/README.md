# Logos

The unit block mark. `tokensec-mark.svg` is for light grounds (`ledger` tiles, `seal-fill` held tile). `tokensec-mark-reversed.svg` is for `ledger-deep` only: its tiles are white, so it is invisible on light grounds. `favicon.svg` is the 64px app icon on a `ledger-deep` rounded square. Pair the mark with the Poppins wordmark as the README describes; the wordmark is live text, not a file.
