# TokenSec logo concepts

Five starting directions, not final artwork. Live canvas: https://claude.ai/artifact/AU5ALK5WmvxctJfA3U9fL7. Colours come from `../branding/tokens.json`.

| # | Concept | Idea | Files |
| --- | --- | --- | --- |
| 1 | Unit block (recommended) | One security divided into registered units; the brass tile is your holding. Matches the brand's unit-tile motif and holds up at 16 px. | `1-unit-block-*` |
| 2 | Certificate seal | A share certificate's double border with a brass seal. The inner rule is dropped in the app icon. | `2-certificate-seal-*` |
| 3 | Register T | A T whose stem is a stack of register entries, the newest in brass. | `3-register-t-*` |
| 4 | Fraction | A circle in quarters with the brass quarter lifted out: a share of a company. | `4-fraction-*` |
| 5 | Boxed Sec | Wordmark only, with "Sec" in a solid block. | `5-boxed-sec-*` |

Each concept has:

- `*-mark.svg`: the symbol on light backgrounds.
- `*-mark-reversed.svg`: the symbol on `ledger-deep`.
- `*-app-icon.svg`: a 64 px rounded-square icon for favicons and apps.
- `*-lockup.svg`: the symbol with the TokenSec wordmark and "a CoinPort business".

Concept 5 has `wordmark.svg`, `wordmark-reversed.svg` and `app-icon.svg` instead.

The wordmarks are live SVG text set in Poppins SemiBold. They render correctly only where Poppins is installed or loaded. Convert the text to outlines before using any file in print or for a logo submission.

Before adopting a concept, have a designer refine it and check it for conflicts with existing trademarks.
