# RiskNotice

The general advice warning. Place it beside or directly under any return figure, offering card list or call to invest. Keep it at the same text size as the content it qualifies.

- The consumer provides the title (default “Your capital is at risk”), the body text approved by compliance and a link to the governing document by its real name.
- The warning icon uses `danger`; the text stays `ink` on `paper-sunk` so it reads as a fact, not an alarm.
- Never collapse it, hide it behind a toggle or move it to the footer.
- The wording in the preview is a placeholder. Final text must come from TokenSec's compliance team.
